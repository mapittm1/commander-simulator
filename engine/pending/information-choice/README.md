before any information-choice or library-order correction. They are expected to
fail in the recorded cases and are not selected by the reviewed build recipe.
Their source checksums, native class origins, report digests and actual results
are retained in [the gap record](../../information_choice_gap.json). Baseline
execution uses the pinned TestNG dependency, JDK target17 and the selected JRE17;
compiler and worker limits remain 30/90 seconds. Fixed test sources are trusted
maintenance inputs; uploaded decks cannot select executable test classes.

and choice behavior from working paid/privacy rules. The four-case fixture
passes countering/privacy controls and fails two own-order retention assertions.

used for the isolated corrected source fixtures; these historical bytes stay
